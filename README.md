# Trabajo Colaborativo en Git

Este repositorio contiene la resolución del ejercicio de flujo de trabajo colaborativo utilizando Git colaborativo y GitHub, incluyendo el trabajo con ramas, fusiones automáticas y resolución de preguntas conceptuales.

## Descripción de la Tarea

El proyecto consiste en realizar una práctica colaborativa simulando el trabajo en equipo con Git. Se abarcan los siguientes puntos principales:

1. **Creación y gestión de ramas:** Desarrollo modular de contenidos (Frontend, Backend, Middle-end, etc.).
2. **Fusión de cambios (*Merge*):** Integración de las contribuciones de los distintos integrantes en la rama principal.
3. **Análisis de conflictos y automatización:** Justificación de los mecanismos de fusión automática de Git y el comportamiento del sistema ante conflictos de edición simultánea en una misma línea de código.
